# Destiny Line

Back-end du visual novel interactif **Destiny Line**.

## Front-end

Pour accéder au projet front-end, rendez-vous sur le dépôt suivant :

[DestinyLine](https://github.com/Arkanona/Destiny-Line)

## Lancer le projet back-end

```bash
nodemon .\app.js
node .\app.js
```

Le site sera disponible sur l’URL indiquée par Vite, généralement `http://localhost:3000`.
